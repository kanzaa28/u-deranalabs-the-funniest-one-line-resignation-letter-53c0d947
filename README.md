One line, at most 140 characters — the resignation letter of a cron job that has sent the same disk-space alert 214 times and been read zero times — written by `main.ts` to `/output/entry.txt` for make.fun's "The Funniest One-Line Resignation Letter" bounty ($10 in USDC).

> I have sent the same disk 92% full email 214 times. You have read zero of them. I quit.

87 characters, well inside the 140-character gate. No quotation marks, no stage directions, no explaining the joke.

## Run it

```sh
node main.ts
```

It writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the directory if needed. The output is deterministic: the same bytes on every run.
